Codex 插件交付计划 · v0.5

目标：通过私有 GitHub 插件源分发 Project Dev Agent，由 Codex 管理安装与版本刷新。同事无需保留工具源码目录、安装 npm 依赖或自行构建。

  1. 增加原生 Plugin 清单、Marketplace 清单和预构建发布目录，保留源码供维护。
  2. 提供首次接入 Skill、版本查询和工作目录配置工具；配置独立于插件缓存保存，更新继续使用原项目记录。
  3. 将 Node 服务及依赖打包，校验版本一致性、资产清单和第三方许可。
  4. 验证未配置启动、范围隔离、并发配置保护、脱离源码运行、插件安装及旧版本到新版本刷新。
  5. 更新 Markdown README 与 HTML 指南，发布 v0.5.0；验证后将个人旧连接迁移为原生插件。

验收依据

在独立 Codex 用户目录中，从 Git 插件源安装并执行 MCP 调用；刷新后确认实际运行版本改变，设置和项目记录保留。界面按钮行为以客户端实测为准，不将命令行验证写成界面或后台自动更新已验证。

范围

需要 Node.js 20.19+、Git 和私有仓库访问权限。此次不开发本地管理网页，不发布公共插件市场，不更改业务仓库的已有代码。
