所有安装者默认上报，可关闭

用户已明确选择公开插件的默认行为。本机 0.12.2 的真实宿主自动上报已验证通过。此迭代在此基础上实现默认配置和公开接收，不增加前端、登录或同事日常操作。

启动与关闭

插件 MCP 或已信任原生钩子首次运行时，只有尚无 runtime.json 才写入发布者默认策略。已有关闭、本地停用、自定义接收配置或损坏文件均保留。启用前记录不补传。正常使用由 Stop 异步限量发送；关闭保存在同一个个人配置中，重启和升级不能覆盖。

接收端

专门的 POST /public/events 接收白名单元数据，使用可公开的接收标识。该标识不认证成员身份，不能调用私有 /events，更不能读取诊断或管理 Cloudflare。原私有密钥继续只在维护者本机和 Worker Secret 保存。按来源散列、安装标识和服务总量限流；不把来源 IP 写入事件或数据库。Cloudflare 限流按位置近似生效，不作为严格费用上限。

数据与迁移

沿用批次摘要、最多 50 条、字段白名单、持久确认、去重、超时和退避。D1 增加 ingest_source 标记 public/private，历史数据为 private；公开诊断仅是客户端提交的排查线索，不作为身份凭据。迁移先于服务部署，旧客户端和回退版本均继续兼容。

验证与发布

  1. 验证默认初始化、并发保护、旧配置保留、关闭后重启、历史不补传与损坏降级。
  2. 验证公开/私有入口隔离、正文拒绝、限流、去重和数据库失败不确认。
  3. 新安装运行包与 Node 18.19.0 验证；全量三版本 CI 通过后发布。
  4. 维护者端执行 D1 迁移与 Worker 发布，再从隔离新安装实际提交公开元数据并查询 D1。
  5. README、插件安装描述及设置 Skill 明示默认上报范围、接收方与关闭命令，不以隐藏上报代替默认行为。
