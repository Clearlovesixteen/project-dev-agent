安装与日常使用

安装一次，在工作目录内的不同仓库使用；任务和知识各自保留。

v0.4.0 · 项目结构与业务理解2026.10.14约 4 分钟阅读

从 GitHub 安装（v0.4）

环境要求：Node.js 20.19+、npm、Git、已登录的 Codex，以及 私有仓库的访问权限。工具使用当前 Codex 会话完成代码理解和修改，无需另配模型 API Key。

首次克隆到长期保留的目录。SSH 方式需要已经配置 GitHub 密钥；也可使用已认证的 HTTPS 地址 https://github.com/Clearlovesixteen/project-dev-agent.git：

bash
git clone git@github.com:Clearlovesixteen/project-dev-agent.git
cd project-dev-agent
npm ci --ignore-scripts
npm run build

注册一次即可用于工作目录下的多个独立 Git 仓库。将下文 /absolute/workspace 换成自己的绝对路径，也可以是单个仓库：

bash
node dist/src/cli.js connect --workspace /absolute/workspace
node dist/src/cli.js connect --workspace /absolute/workspace --apply

第一条预览，第二条执行。它通过 codex mcp add 添加 project_dev，并将 Skill 安装到 ~/.agents/skills/project-dev。其他 MCP 连接保留。同名连接或自定义 Skill 存在冲突时保留原内容。安装器可识别未经修改的 v0.2.1 / v0.3.0 Skill 并原位升级；其他差异需先核对。

若终端找不到 codex，给两条命令增加 --codex /absolute/path/to/codex。macOS 的本次桌面安装所用路径为 /Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex，其他机器应以实际安装路径为准。

Codex 桌面、CLI 和 IDE 共享用户 MCP 配置。配置说明见 官方 MCP 文档。安装后在目标仓库新建 Codex 会话；若还没有工具，在 Settings → MCP servers 中重启 project_dev 连接，再开始新会话。

直接开始一个需求

在工作目录内的具体仓库打开会话，例如：

text
$project-dev 帮我实现这个需求：……

Codex 会先建立项目结构索引，寻找模块、公共组件和直接引用；随后自动扫描本机该仓库的历史对话，逐批提取带来源的习惯候选，并恢复已完成的分析进度；随后读取当前代码与规则，建立验收项和关联清单，再修改并验证。在第一批知识尚未整理时，直接利用已有代码、AGENTS.md 和业务文档。

首次使用时，project_prepare 只向 Git 本地的 info/exclude 追加 /.project-dev/local/；它不修改业务文件、共享 AGENTS.md 或 .gitignore。任务和候选经验随后写到忽略目录。可以只预览：

bash
node /absolute/installed-package/dist/src/cli.js project prepare --project /absolute/repository

开始任务要求工作树干净。已有改动时先保留，由开发者决定完成提交还是使用干净 worktree。工具不会替你 stash、reset 或 commit。workspace 模式要求工作树及其 Git 元数据都位于配置目录内；位于目录外的 Codex 托管 worktree 暂不包含在此连接范围。

切换会话后可说：

text
$project-dev 继续当前仓库上次未完成的任务，先恢复记录。

task_check 不传任务 ID 时恢复当前仓库的唯一活动任务。一个仓库的任务不会自动转移到另一个仓库；每次工具调用都传当前 Git 根目录。根目录含多个项目时，应打开具体项目或在请求中点明项目。

仅希望先看项目习惯时可输入 $project-dev 分析当前项目的历史习惯，给我查看报告。历史分析允许工作区已有业务改动；正式任务仍要求干净基线。已扫描但未完成分析的批次会续接处理。原始历史只读，候选与报告写入本地忽略目录，细节见 历史习惯发现。

只做项目接入时可输入 $project-dev 接入当前项目，生成项目理解报告。具体需求再逐步记录术语、业务流程、职责与源码依据；相关文件变化后会提示复核。结构扫描与历史整理均允许已有业务改动，正式任务仍要求干净基线。详见 首次扫描与业务理解。

纠正与知识积累

直接在对话中指出实现方式及原因，例如“这里应复用现有封装，另外两个入口也要同步处理”。Agent 会更新当前任务，并可把适合复用的经验写成候选草稿。候选内容不会自动升级为团队规则。

需要共享时，按 经验审查 核对适用范围、来源和问题，再显式审查。共享知识放入项目的 .project-dev/knowledge/，通过普通 Git 审查维护。团队成员安装相同工具并拉取知识即可使用，不需要中央服务。

团队接入

先让个人试用经过真实需求验证，再按 试用指南 收集纠偏次数、关联遗漏及额外操作成本；不能以测试通过替代团队收益评估。

每位同事获得私有仓库访问权限后，从 GitHub 克隆、构建并执行上面的 connect，workspace 使用自己的本地路径。MCP 服务运行在各自电脑，项目历史、扫描结果和任务记录保存在各自项目的本地忽略目录。若需统一项目配置、Skill 和共享说明，可执行原有 project init --project /absolute/repository 预览，再带 --apply 写入；这会产生团队需要审查的 Git 变更。个人模式不要求先执行该命令。团队级 Skill 与全局 Skill 应保持同一版本，避免旧的项目 Skill 遮蔽新版本。

从 GitHub 更新

在工具源码目录执行以下命令，依次完成每一步，任何一步报错都先处理后再继续。--ff-only 会在本地分支有分叉时停止。更新后重新连接是为了同步 Skill，随后在 Codex 中重启 project_dev 并新建会话，让 MCP 使用新代码：

bash
git pull --ff-only
npm ci --ignore-scripts
npm run build
node dist/src/cli.js connect --workspace /absolute/workspace --apply

保留首次连接时的工具目录、Node 路径和 workspace。遇到 SKILL_CONFLICT 或 MCP_CONFIG_CONFLICT 时先核对差异；安装器会保留自定义内容。发布者在修改 Skill 时需同时提供对上一版本的升级支持。仓库中的 v0.4.0 标签记录本次共同验证的基线。

已通过安装包接入的人，若要迁移到 GitHub 目录，应先使用原安装目录的 disconnect --workspace /absolute/workspace --apply 断开匹配的旧连接，再从新目录执行 connect。项目任务和历史记录会保留。

当前交付方式为 Git 源码安装与更新；Codex 插件市场的一键安装、自动更新入口尚未提供。仓库首页使用 README.md，可直接在 GitHub 阅读。详细说明使用 HTML，克隆后用本机浏览器打开 guide.html 即可阅读。

断开与保留数据

bash
node /absolute/installed-package/dist/src/cli.js disconnect --workspace /absolute/workspace
node /absolute/installed-package/dist/src/cli.js disconnect --workspace /absolute/workspace --apply

断开仅移除匹配的 project_dev 连接和未经修改的已安装 Skill 文件；自定义冲突会先停止。项目任务、知识、Git 本地忽略规则和工具安装目录均保留，需要时重新连接即可。它不是清理开发成果的命令。

排查

  • 找不到 Skill：确认安装结果的 Skill 路径，并新建会话。
  • 找不到 MCP 工具：检查 Settings → MCP servers / /mcp，或 codex mcp get project_dev --json；重启连接。
  • PROJECT_OUTSIDE_WORKSPACE：当前仓库或 Git 元数据位于配置目录外；核对实际项目路径。
  • WORKTREE_DIRTY：先处理已有改动；不要为满足工具而自动丢弃或提交内容。
  • ACTIVE_TASK_EXISTS：用 task_check 恢复，不能随意新建替换旧任务。
  • BASELINE_BRANCH_CHANGED：已经切换分支；返回原分支继续，或明确中止旧任务。
  • SKILL_CONFLICT / MCP_CONFIG_CONFLICT：同名配置不一致；保留原内容后比较，不覆盖未知配置。
  • doctor 只验证 Node/Git/SDK 初始化；它不证明桌面当前会话已加载连接。
